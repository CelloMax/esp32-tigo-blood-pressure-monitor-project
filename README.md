# esp32-tigo-blood-pressure-monitor-project
It a blood pressure monitor that is built using  Esp32 TTGO with sim800 on board, l293d, HX710B sensor, buzzer and LCD 

## Hardware Schematic

The complete wiring diagram for the ESP32 TTGO T1 V1.3 blood-pressure monitor is shown below.

![ESP32 Blood Pressure Monitor Schematic](hardware/bp_monitor_schematic.png)

### Main Components

- ESP32 TTGO T1 V1.3
- HX710B pressure sensor
- Pressure transducer
- L293D motor driver
- DC air pump
- Solenoid valve
- BC547 transistor
- 1N4007 flyback diode
- Buzzer
- OLED I2C display
- Start/Stop/Mode buttons
- 5V power supply
- AMS1117-3.3V regulator
